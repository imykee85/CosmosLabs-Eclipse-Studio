# Security policy

If you find a security problem in Eclipse, please report it privately and do not open a public issue.
Use GitHub's "Report a vulnerability" button on the Security tab of this repository (private vulnerability reporting), or write to the contact address shown on https://eclipse.cosmoslabsai.com/privacy.

Please include what you found, how to reproduce it, and what it could affect. We will reply as soon as we can. Do not access other people's data, run denial-of-service tests, or test with real payments.
