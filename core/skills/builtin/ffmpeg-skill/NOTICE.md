# ffmpeg-skill (vendored)

The `scripts/` and `templates/` folders are copied unchanged from **ffmpeg-skill 2.17.1** by **kajisho5** (https://github.com/kajisho5/ffmpeg-skill), MIT licence (see `LICENSE`, Copyright (c) 2026 kajisho5). Cosmos Labs AI uses them inside Eclipse's cloud sandbox (job kind `media.edit`) to cut, join, reframe, caption and export the person's own videos. Only the standard library of Python 3 and ffmpeg are needed. Nothing here runs on Eclipse's own servers.
