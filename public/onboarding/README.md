# Onboarding welcome video

`welcome.mp4` (H.264) and `welcome.webm` (VP9) are the Seedance clip that plays full-screen after a new user finishes onboarding, muted, with the line "Step into a world of endless possibilities" typed over it; then they continue to the dashboard. The original upload (with sound) and the earlier test clip are in `media-archive/onboarding/`.
If the file is missing, a branded "Welcome to Eclipse" screen plays instead.
