# Onboarding welcome video

`welcome.mp4` (H.264) and `welcome.webm` (VP9) are the Seedance clip that plays full-screen, muted, after a new user finishes onboarding, behind the "Welcome to Eclipse / Setting up your studio…" screen; then they continue to the dashboard. The original upload (with sound), the earlier test clip and the "Step into a world of endless possibilities" typed-line version are described in `media-archive/onboarding/`.
If the clip cannot play, the same screen shows on black.
