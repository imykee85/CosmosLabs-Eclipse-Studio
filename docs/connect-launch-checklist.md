# Connect ("Your creative computer"): launch checklist

Goal: Connect behaves like a computer. It chats like a strong AI assistant, runs skills, builds and runs mini apps, connects to external apps (TikTok, Instagram, X, Google Drive and more), and remembers everything. Everything below must be done, or its claim left out of the public copy, before launch.

Legend: **[You]** needs the owner (accounts, approvals, keys, decisions) · **[Me]** Claude Code builds it · **S / M / L** rough effort · "Config" = Vercel env var that is not secret · "Secret" = Vercel env var that must stay secret.

Public copy rule: only claim what is checked off here. Today's copy ("Ask for anything, run skills and tools, keep a memory of your work, and send it to your apps.") is limited to chat, skills, tool recipes, memory, and Telegram/Slack sends.

---

## 2. Safety before anything can post publicly (do before connecting more apps)

- [ ] **[Me]** Confirm-before-send: the assistant shows exactly what it will post and where, and waits for the user's OK. No send without a visible approval. (M)
- [ ] **[Me]** Per-app permissions: the user chooses, per connected app, "ask every time" or "allow". Default is ask. (M)
- [ ] **[Me]** Prompt-injection guard: text that comes from connected apps, files or web pages is treated as data, never as instructions; add tests with hostile examples. (M)
- [ ] **[Me]** Moderation on chat: run the existing prompt check on what the assistant is asked to make and send. (S)
- [ ] **[Me]** Audit log: every send and every connected-app action is recorded (who, what, where, when) and visible to the user. (M)
- [ ] **[Me]** Rate limits per user for chat, sends and renders, with clear messages. (S)

## 3. External apps

Each app needs its own developer app and approval; start the slow ones first. For every app: sign-in flow, tokens stored encrypted (existing `secret-box`), refresh, disconnect, a send action, and a test with a real account.

- [ ] **[You]** Register a developer app and request approval for: Instagram (publishing), TikTok (content posting), X (posting), YouTube, Google (Drive, Gmail, Calendar). Instagram and TikTok publishing approval can take weeks. (L, mostly waiting)
- [ ] **[Me]** Shared OAuth plumbing: start/callback routes, state check, token storage, refresh, disconnect. (M)
- [ ] **[Me]** Google Drive: connect, list/search files, read a file into a chat, save a render to a folder. Do this first, it is the easiest to get approved. (M)
- [ ] **[Me]** X: post text and a picture. (M)
- [ ] **[Me]** Instagram: publish a picture or short video (needs a business account and approval). (L)
- [ ] **[Me]** TikTok: publish a video (needs approval, and video exists first). (L)
- [ ] **[Me]** YouTube: upload and set title/description. (M)
- [ ] **[Me]** Replace stand-in logos (Outlook, OneDrive, Frame.io) with official artwork. (S)
- [ ] **[Me]** Remove or hide any app in the list that is not connectable on launch day, or mark it honestly. (S)

## 4. Mini apps (build tools)

- [ ] **[You]** Decide what a mini app is: single-page web app generated by the assistant, saved per user, runnable and shareable. (decision)
- [ ] **[Me]** Assistant tool to create and edit a mini app (HTML, CSS, JS in one bundle) and save it per user, with versions. (M)
- [ ] **[Me]** Safe runner: apps run in a sandboxed frame with no access to the user's session, our keys, or other users' data; allowed network calls are limited. (L)
- [ ] **[Me]** Tools page lists the user's mini apps, opens, re-runs, renames, deletes; the built-in tool recipes stay as starters. (M)
