# Sources and reuse

Checked against the linked primary documentation on 2026-11-02. Recheck provider terms when using a new provider or distributing a commercial workflow.

- **Wikimedia Commons:** original files, descriptions, authors, and per-file licensing are available through the MediaWiki API and file pages. A Commons host is not itself a license. Include verified CC BY-SA alongside CC0/public-domain and CC BY by default, carry credit and modification notices, and flag share-alike conditions for adaptations as specified in each license. If a user needs to avoid these conditions, exclude BY-SA. [Reuse guide](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia), [API image metadata](https://www.mediawiki.org/wiki/API:Imageinfo), [Commons API examples](https://commons.wikimedia.org/wiki/Commons:API/MediaWiki).
- **Flickr:** use the individual photograph's license, not the account's default or a search snippet. License-filtered discovery is available, and its API needs an application key. This package does not require a Flickr key; verified images can be imported through the manifest. [Creative Commons browsing](https://www.flickr.com/creativecommons/), [search API](https://www.flickr.com/services/api/flickr.photos.search.html).
- **Google Street View:** use links for the user's own scouting. Google restricts screenshots, downloading imagery outside its services, and application-based extraction. Maps/Places photo display access does not grant a general image-pack export license. [Geo guidelines](https://about.google/brand-resource-center/products-and-services/geo-guidelines/), [Places photo policies](https://developers.google.com/maps/documentation/places/web-service/policies).
- **Owned or separately licensed photos:** import only after the user supplies them or their source and permission are established. Record the permission's scope in `authorization_note` and its evidence in `license_evidence`. A venue's press gallery or stock site may limit modification, redistribution, or uploading to generation services; inspect those terms for the intended workflow.

The helper records a practical license classification, not a legal certification. Retain source records so the filmmaker can meet applicable credit and reuse conditions. Do not describe a generated interpretation as a documentary photograph of the place.
