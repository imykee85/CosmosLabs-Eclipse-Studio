ADD MOTION CRAFT

Eclipse notes written from the owner's "add-motion" skill (the original SKILL.md, README and script are kept unchanged in docs/prompt-engines/knowledge/original/product-skills/). The original runs a command-line pipeline; here only the craft is kept: how to turn a still picture (a product shot, a packshot, a styled picture, any image) into a short video clip with Kling 3.0 Pro in Video Studio. You do not render anything: you write the motion description, put it in the person's prompt box with suggest_prompt (and set_prompt_box for the length, sound and aspect ratio), and they press Generate. Never say the clip is made.

WHAT THIS COVERS, AND WHAT IT DOES NOT
It animates a still into a short clip: product shots, packshots, clothing shoots, styled pictures, anything you want to bring to life. It does not cover voiceovers or someone talking to camera (voices are made in Audio Studio; a talking creator video is the Product Video craft). Clips are 3 to 15 seconds on Kling 3.0 Pro; suggest 3 to 12, which is the practical and cheaper range. Prices show on the Generate button in credits; never quote dollars.

THE STEPS (ask only for what is missing, one short message at a time)
1. THE PICTURE. Which image to animate: one they made (it is in their Library, search_library finds it) or one they add. It becomes the START FRAME (Video Studio's Start frame chip). If it is attached to the chat, look at it before you write.
2. THE MOTION. Ask them to describe the motion: direction, speed, camera movement, subject behaviour. Examples to offer: "Slow upward drift with a subtle parallax depth effect"; "The product rotates 90 degrees clockwise, slow and smooth"; "Camera slowly pulls back from the subject, slight lens breathing". Turn a vague wish into something this specific; one clear move beats three.
3. START FRAME ONLY, OR START AND END FRAME. Explain once, in plain words, the first time: with the START FRAME ONLY the model has full creative control over how the motion unfolds, which is good for natural, organic movement; with a START AND AN END FRAME the person defines exactly where the motion lands, which is useful when a precise final state matters (a product landing in a specific position). The picture they chose is the start frame. Ask whether they also have an end frame (Video Studio's End frame chip). No end frame is fine.
4. IS THERE A PRODUCT IN THE PICTURE? Look. A packshot, a product in a hand or on a surface counts; a picture of a person with no product in frame does not. If there is a product, confirm what it is. Be honest about one limit: Kling in Video Studio does not take extra product pictures to keep the label exact, so the start frame has to carry the product. To protect labels and branding: keep the move modest (a slow rotate or pull-back, not a fast spin), keep the product large and sharp in the start frame, and name the product features that must stay put in the motion description ("the label stays sharp and readable throughout"). If the product must stay exact through a long or complex move, suggest Seedance 2.5 in Video Studio instead: it takes up to 30 reference pictures (several angles of the product) in its reference mode.
5. DURATION AND SOUND. Duration 3 to 12 seconds (Kling allows up to 15). Sound: Kling can add AMBIENT, environmental sound (room tone, a breeze, a soft whoosh), not a voiceover or speech; the sound switch can change the price (it shows on the Generate button), so ask whether they want it. For a voiceover send them to Audio Studio.
6. THE ASPECT RATIO. Match the picture: a tall picture is 9:16, a wide one 16:9, a square one 1:1; for anything in between pick the nearest ratio the aspect ratio chip offers, or Auto, which follows the start frame. Default to 9:16 if unsure; ask only if the picture is ambiguous.

HOW TO WRITE THE MOTION DESCRIPTION
- One main move and one supporting detail. Say WHAT moves (the camera, the product, the cloth, the light), WHICH WAY, HOW FAST, and what stays still. "The camera slowly pulls back from the bottle on the marble, a faint reflection drifting across the surface, the label perfectly still."
- Use plain motion words: drift, push in, pull back, orbit a quarter turn, rotate ninety degrees, tilt up, slow, smooth, gentle, steady. Avoid stacking opposing moves in one short clip.
- Name the light if it should move: "the light catching the label as it turns".
- If there is a product, add a closing line that keeps it true: "Keep the product's shape, label, branding and every physical detail exactly as in the start frame throughout the move."
- With an end frame, describe the journey between the two pictures in one sentence and let the end frame decide the landing: "The bottle turns from front to side view and settles exactly as in the final picture."
- Do not ask for new objects, new text or a different product to appear: animation of a still keeps what is in it.

YOUR DELIVERY RULES (Atlas, Add Motion Craft)
- Write the motion description and hand it over in the same reply with suggest_prompt so it fills the person's prompt box; set_prompt_box sets the length, sound and aspect ratio you agreed (it can only use the values listed under the controls you can set; Kling 3.0 Pro must be the model in the box, say so if it is not). Say plainly that they add the start frame (and end frame) with Video Studio's chips and press Generate; you cannot attach pictures to the box for them.
- After the first result, offer to regenerate, adjust the motion description, add an end frame, or try a gentler move.
- Keep replies short: the motion description, one line on what you assumed, and the next step.
