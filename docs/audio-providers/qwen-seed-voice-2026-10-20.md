# Qwen voice (instruct, cloning) and Seed voice: what is confirmed (2026-10-20, pasted by the owner)

Summary of the owner's pasted reference (read by Claude from the official pages). Anything marked NOT CONFIRMED must not be built from memory.

- Alibaba moved to new voice models: `qwen-audio-3.0-tts-plus/-flash` and `qwen-audio-3.1-tts-plus/-flash` carry voice cloning AND instruction control (field `instruction`). The old `qwen3-tts-flash` (what Eclipse uses today) is HTTP-only with no cloning and no instruction control. `qwen3-tts-instruct-flash` is no longer on any current page.
- Qwen cloning (confirmed): `POST https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/api/v1/services/audio/tts/customization`, Bearer key, `model: "voice-enrollment"`, `input.action` create_voice / list_voice / query_voice / update_voice / delete_voice. create_voice: `target_model`, public `url` of the sample, `prefix` (letters/digits, max 10), optional `language_hints` (one element), `max_prompt_audio_length` 3 to 30 s, `enable_preprocess`. Returns `output.voice_id`. Status DEPLOYING / OK / UNDEPLOYED: poll until OK. Synthesis must use the same target model.
- NOT CONFIRMED (blocks building Qwen): the synthesis request for qwen-audio-3.x (WebSocket `run-task`/`continue-task`, JSON path of `instruction`, Singapore endpoint), sample format and size limits, voices per account, price. Needed: the "Qwen-Audio-TTS WebSocket" page and the regions/endpoints page.
- Seed voice cloning: training call is `POST https://voice.ap-southeast-1.bytepluses.com/api/v3/tts/voice_clone` with `X-Api-Key` (BYTEPLUS_VOICE_API_KEY), `X-Api-Request-Id`, `speaker_id: "custom_speaker_id"`, `custom_speaker_id`, base64 `audio` (max 10 MB, 14 to 15 s, WAV mono), `language` int, optional `text`, `extra_params.demo_text`. The slot fee is charged at the FIRST synthesis with the voice, not at training. NOT CONFIRMED (blocks building): the Seed TTS 2.0 synthesis request for a custom voice, error codes, slot fee amount.
- Seed ASR 2.0 (transcription): audio-file mode, $0.12 per hour of audio (Eclipse price 0.5 tenth per minute), 51 languages, diarization zh/en only. NOT CONFIRMED (blocks building): endpoints, request fields, limits. Needed: the ASR 2.0 "Audio File" API page.
- Rules kept: consent checkbox before any cloning; bill audio by server-measured duration rounded up to the second; same-language cloning only (no cross-lingual).
