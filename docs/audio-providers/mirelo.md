# Mirelo (sound for video and sound effects): reference and what is built

Saved from the owner's master brief (Part 7, read 2026-10-17). The sandbox could NOT reach api.mirelo.ai (proxy 403), so `GET /v3/openapi.json` was never read: everything marked VERIFY below must be checked with a real key.

## Reference
- Base `https://api.mirelo.ai`, `Authorization: Bearer sk-...` (key shown once; Mirelo Studio, API Keys). `/v3` routes only (the old V2 routes are not used). `GET /v3/me` = credits and billing mode (unmetered keys report `credits: null`).
- Model `sfx-2.0` (default, 48 kHz mono, prompt up to 2000 characters, negative prompt up to 1000 (experimental on text), text duration 100 to 600000 ms, video 1000 to 600000 ms, 1 to 4 variants, `preserve_speech` on by default, no loop, no stems). `sfx-1.6` (extend, inpaint, stems, loop) is NOT registered. Output formats wav, flac, mp3_128/192/256/320.
- Create: `POST /v3/text-to-sfx/generations?wait=25` or `/v3/video-to-sfx/generations?wait=25`; quote: the same path plus `/preflight`. Body `{model, duration_ms, num_variants, input:{prompt, negative_prompt, video:{type:"url", url}}, controls:{preserve_speech}, output:{format}}`. 200 = done inside the wait, 202 = running; follow `urls.self` (HTTP 200 even for a failed job: branch on `status`: queued, running, succeeded, partially_succeeded, failed, canceled, expired; each variant has its own status). Jobs live 24 h; audio is deleted by Mirelo after 7 days. Downloads may redirect: never send the key to the redirect target.
- `Idempotency-Key` on creates (same key and body returns the original job, 24 h). Concurrency default 5 jobs per key. Errors `{error:{code,message,param,retryable,request_id}}`: invalid_request, capability_unsupported, invalid_video, asset_not_ready (retry), insufficient_credits (402), idempotency_conflict (409), not_found, result_unreadable, sync_too_long (422), max_credits_exceeded.
- Price: 15 credits per second per variant (10 until 2026-12-12). A partner listing shows $0.010 per second until 2026-12-13, then $0.015. The dollar price per credit is NOT STATED by Mirelo's pages.

## What is built (2026-10-17)
- Adapter `src/lib/audio/providers/mirelo.ts` (plain fetch): `preflight`, `start` (create with wait=25 + Idempotency-Key = our job id), `poll` (only an address on Mirelo's own host is followed; partially succeeded keeps the good variants), downloads without the key on redirects. Errors in `mapMireloError` (`errors.ts`). Provider interface gained `preflight`, `pollUrl` and `AudioResult.variants`.
- Registry `sfx-2.0` (kinds `sfx` and `vsfx`, per second per variant, launch price until 2026-12-12, `MIRELO_PRICE_PER_SECOND` Config value replaces it). Job kind `vsfx` ("Sound for video"). `jobs.ts`: the price is quoted from Mirelo first (`MIRELO_CREDIT_USD`, default 0.001 USD per Mirelo credit, PROVISIONAL), held, and settled from the credits Mirelo reports for the variants that succeeded; alternatives are stored at `audio/<user>/<job>/variant-<n>.<ext>` and listed in `AudioJob.result.variants`; deleting a take removes all of them. `POST /api/audio/quote` returns the price without starting anything; `GET /api/audio/<id>/file?variant=n`.
- UI: Voice Studio Effects mode shows Mirelo with variants, file format, "leave out" (experimental), lengths up to 10 minutes, no Auto, Loop greyed ("Not supported by Mirelo SFX 2.0"); takes with variants or a video show `SoundTake` (video muted and the chosen sound played in step). "Add sound" on every finished video's details (`AddSoundDialog`): optional description, Keep speech, 1 to 4 variants, WAV or MP3, price before confirming.
- Settings: `MIRELO_API_KEY` (Secret), optional Config values `MIRELO_BASE_URL`, `AUDIO_MIRELO_MAX_CONCURRENCY` (default 5), `MIRELO_CREDIT_USD`, `MIRELO_PRICE_PER_SECOND`. Listed in `/admin/health`.
